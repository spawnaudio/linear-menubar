# Linear Focus v1.0 MVP

## Product Definition

Linear Focus v1.0 is a native macOS menu bar app for focusing on one Linear issue at a time. A user selects an assigned issue, chooses a duration from 1–480 minutes, and starts a session with a small draggable floating countdown that remains available above normal windows.

When a session starts with status updates enabled, the app re-checks the issue and moves it to an active Linear status. Status selection prefers Working, then In Progress, then the first active status by position. Finishing or ending a session does not mark the issue complete.

## MVP Scope

- Native SwiftUI macOS app with an AppKit menu bar item.
- Draggable, nonactivating floating timer panel.
- Assigned Linear issue loading through GraphQL.
- Manual refresh, pagination, search within loaded issues, and issue links.
- Personal API key storage in macOS Keychain.
- Configurable sessions with presets of 15, 25, 45, and 60 minutes plus custom durations.
- Start, pause, resume, extend, finish, and session restoration.
- Linear active-status update before a session begins.
- Local session history and completion sound.
- Demo mode with isolated sample issues and history.
- Persistence across app closure, relaunch, and elapsed wall time.

## Explicit MVP Boundaries

- No automatic issue completion.
- No Linear time logs or comments.
- No OAuth onboarding or login-at-startup flow.
- No browser extension.
- No AI features.
- No background alarm after the app is quit.
- Development build only; Developer ID signing and notarization are not included.
- The Electron/React implementation remains a separate experimental prototype.

## Validation Completed

Validation was recorded on 6 September 2026 on an Apple silicon Mac running macOS 27 with the installed Xcode-beta toolchain.

- 19 automated tests passed across timer behavior and mocked Linear API suites.
- Release app built successfully and was locally ad-hoc signed.
- Native UI smoke test passed start, pause, extension while paused, saved-state restoration, resume, expiry, history, and panel show/hide.
- Floating panel configuration was checked for window level, all Spaces, full-screen auxiliary behavior, visibility while inactive, and keyboard focus behavior.
- Eight native renders were visually reviewed: issue selection, active session, collapsed timer, hover controls, finished timer, history, settings, and welcome.
- `codesign --verify --deep --strict` and Info.plist validation passed.
- Shell script syntax and `git diff --check` passed.
- Demo and UI tests use isolated preferences and do not call Linear or read Keychain.

## Validation Still Required

- Connect a real scoped Read/Write Linear API key.
- Verify a live issue status mutation before the timer starts.
- Confirm completed and canceled issues are not reopened.
- Verify Keychain behavior with a real credential.
- Test physical sleep/wake behavior.
- Test dragging across real displays and full-screen applications.
- Test VoiceOver and accessibility behavior.
- Test Intel Macs and older supported macOS versions.
- Complete Developer ID signing and notarization before distribution.

## MVP Acceptance Criteria

- A user can connect Linear, select an assigned issue, choose a duration, and start a session.
- The selected issue is moved to an active status before the countdown begins when status updates are enabled.
- The floating timer remains accessible from the menu bar and supports pause, resume, extension, and opening the main window.
- Running and paused sessions restore correctly after app closure and relaunch.
- Demo actions remain isolated from live Linear data.
- API and timer failures leave the session in a safe, understandable state.
- The app does not mark issues complete when a timer finishes.
